# Max's Credits Plan · v1.6.0

给小学生设计的**好习惯积分系统**（品牌名 = 孩子英文名 + Credits Plan，默认 Max）：完成任务赚 Credits，商店兑换奖励，月底未花的 Credits 自动过期 10%（倒逼消费，也倒逼「赚」）。

## 打开即用

- **双击 `index.html`**，用任意现代浏览器打开（Chrome / Safari / Edge 均可）
- **无需服务器、无需联网、无需安装**
- 完整历史版本见 `versions/index-v1.2.0_260827.html`

## Roadmap

- **v1.7 候选 · 云同步**（多端尤其手机）：候选方案 ① JSON 导出 + 网盘手动同步（零成本先行） ② 轻后端账号制同步；需先定数据冲突策略
- **移动端 PWA**：manifest + 离线缓存 + 添加到主屏幕

## 管理员账号与找回

- 爸妈后台 → 系统设置 → 填写 **管理员邮箱 + 密码（≥4 位）→ 保存**
- 保存后进后台需邮箱 + 密码登录；密码只存 SHA-256 哈希，不存明文
- 忘记密码：登录框点「忘记密码?」→ 输入注册邮箱校验 → 直接设置新密码
- 登录/找回完整流程演示：打开 `tests/demo-admin-login.html`（独立存储，不影响正式数据）
- 旧版 4 位 PIN 仍兼容；一旦保存管理员账号即自动升级为新体系

## v1.5 亮点

- **M-Coin 货币彩蛋**：货币符号是金色硬币中间的孩子首字母「M」🪙 —— 换孩子只需改 index.html 里的 `CHILD_INITIAL` 常量

- **字体版权**：唯一嵌入字体 Baloo 2（圆润英文数字展示字体）为 SIL Open Font License 1.1，明确允许子集化嵌入；正文一律设备系统字体，零嵌入零风险

### 超级管理员后台 6 张卡片

1. **运营总览** — 当前余额 / 本月入账出账 / 月底将扣 / 累计获得消费 / 今日完成 / 近 7 天日均 / 记录条数
2. **数据统计** — 近 7 天入账柱状图 + Top5 最常完成任务
3. **快捷调整** — ±10 / ±50 一键调整余额、撤销上一笔、清空今日完成
4. **规则调参** — 28 任务 + 21 奖励可改分值/价格/启停（含恢复默认）
5. **系统设置** — 过期比例 / 起步余额 / 过期开关 / **管理员 PIN**
6. **数据管理** — 导出 JSON / 导出 CSV / 导入 / 重置

## 数据存哪

全部存在浏览器 **localStorage**，键名为 `max_credits_v12`。

- 同一台电脑、同一个浏览器打开，`index.html` 会自动读取上次的数据
- 换电脑 / 清浏览器缓存会丢失，建议定期在「爸妈控制台 → 导出数据」备份 JSON 或 CSV
- 忘记 PIN 可在浏览器开发者工具里清除 `localStorage` 里的 `max_credits_v12`（会丢所有数据）

## 迁移与备份

1. 爸妈控制台 → **导出数据 (JSON / CSV)**，下载备份文件
2. 新设备打开 `index.html` → 爸妈控制台 → **导入数据**，选择 JSON 即可恢复

## 自动化检查

浏览器地址栏改成 `file:///.../index.html?selftest`（末尾加 `?selftest`），打开后按 F12 看控制台，会输出 13 项核心规则自检结果。

开发者排查时也可在控制台输入：

```js
window.MAX.doTask('t_dawn')   // 完成起床任务
window.MAX.doReward('r_cash') // 兑换现金
window.MAX.reset()            // 重置全部数据
```
