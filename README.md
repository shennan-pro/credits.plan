# Kid's Credits Plan · v2.2.3

给小学生设计的**好习惯积分系统**（品牌名 = 孩子英文名 + Credits Plan，默认 Max）：完成任务赚 Credits，商店兑换奖励，月底未花的 Credits 自动过期 10%（倒逼消费，也倒逼「赚」）。

## 打开即用

- **双击 `index.html`**，用任意现代浏览器打开（Chrome / Safari / Edge 均可）
- **无需服务器、无需联网、无需安装**
- 完整历史版本见 `versions/index-v1.2.0_260827.html`

## 初始向导与角色

- 首次打开（或地址栏加 `?register`）进入三步向导：**① 孩子档案**（英文名必填）→ **② 家长账号**（邮箱+密码，可稍后再设）→ **③ 完成**
- 孩子是积分的主人；**家长默认管理员**：看全部数据、调规则、改主题、管安全
- 后台顶部分「📊 运营 / 🎨 定制工坊」两组

## 云同步（Supabase，家长后台配置 · v2.5.1 分行 + 表级权限）

多设备共用一套数据（如家长手机 + 孩子平板）：

1. Supabase 控制台 → SQL Editor，执行一次 `supabase-setup.sql`（**v2.5.1 版**）。页面里也有「📋 复制建表 SQL」按钮
   - ⚠️ 阿里云 ADB PG 实例：平台层禁用了 `SECURITY DEFINER`，v2.5.0 的脚本会报
     `SECURITY DEFINER functions are not allowed` → 只能用 v2.5.1 版（不提权）
   - 粘贴建议用 `supabase-setup.paste.sql`（纯 ASCII 无注释，不会被编辑器吃掉 `--`）
2. 爸妈后台 → 定制工坊 → **云同步 · Supabase**：填项目 URL + anon public key
   - URL 官方托管 `https://xxx.supabase.co`、国内托管（如 `xxx.supabase.opentrust.net`）、自建域名都支持
3. A 设备点「🎲 生成」家庭码 + 「🔑 生成」访问密钥（填完不用点保存，直接点「🔌 测试连接」即可）
4. B 设备填同样 URL/key，并手动输入**同一个家庭码 + 同一个访问密钥** → 即可同步
5. 之后开「自动同步」：本地改动自动上云，打开页面自动拉取（拉取前自动备份本地旧档）

**不确定云端支不支持？点「🩺 环境体检」**，一次跑完 5 项探测并给出判定：
- REST 根路径 / 表是否存在 / RPC 函数是否存在
- **直连读（不带凭证）应返回 0 行** → 这就是「表级权限」是否真的生效的证据
- 端到端：临时建行 → 读回 → 删除

**家庭码 vs 访问密钥**
- 家庭码 = 「哪一家」的编号；访问密钥 = 真正的钥匙
- 传给云端的是**凭证** `md5(家庭码:密钥)`，密钥明文从不上云、也不落库
- v2.5.1 起，表对 anon 角色**直连全禁**（RLS 策略 + REVOKE），即使别人拿到 anon public key 也无法列出或改写你的数据
- 密钥错和「不存在这个家庭码」返回同样结果，外部无法探测
- ⚠️ **密钥一旦设置无法找回**（云端只存哈希）。换设备必须填同一个密钥；实在忘了只能删掉该家庭码重新开始
- 旧存档（没填密钥）会用家庭码兜底，云端旧行也允许通过一次并自动升级

- 凭证只存本机浏览器（键 `max_credits_cloud`），不进导出文件
- 冲突策略：整包 last-write-wins；时钟偏差大的设备推送会被跳过（fail-safe）；免费额度下数据量可忽略

## 数据表格 · 批量录入 + 可自定义评分规则（v2.3.0 / v2.4.0）

家长后台 → 定制工坊 → **📊 数据表格**：批量录成绩 / 单元测验，不用一条条点。

1. **没有现成表格？** 点「📄 下载 CSV 模板」→ Excel 打开填好 → 「📥 导入」传回
1b. **导入**：粘贴 CSV，或选 `.csv` / `.xlsx` / `.xls`（表头：日期/名称/科目/方式/类型或等级/分数/满分/积分/备注）
2. **两种评分方式**：分数制（分数+满分，满分 80/100/120 都行）· 等级制（A++~E）
2b. **权重与阶梯可改**：后台「📐 评分规则」卡可切「按满分百分比 / 按绝对分÷标准分」，并增删改分数线与积分映射，改完立即重算
3. **入账**：逐行「入账」或「⚡ 批量入账未记账行」→ 生成正式记录，出现在「记录」页并计入余额
4. **改了已入账的行**：状态变「⟳ 需重记」，点「重记」会先撤销旧记录再按新值入账，**不会重复加分**
5. **导出 CSV** 备份

## 数据存哪

全部存在浏览器 **localStorage**，键名为 `max_credits_v12`。

- 同一台电脑、同一个浏览器打开，`index.html` 会自动读取上次的数据
- 换电脑 / 清浏览器缓存会丢失，建议定期在「爸妈控制台 → 导出数据」备份 JSON 或 CSV
- 忘记 PIN 可在浏览器开发者工具里清除 `localStorage` 里的 `max_credits_v12`（会丢所有数据）

## 迁移与备份

1. 爸妈控制台 → **导出数据 (JSON / CSV)**，下载备份文件
2. 新设备打开 `index.html` → 爸妈控制台 → **导入数据**，选择 JSON 即可恢复
