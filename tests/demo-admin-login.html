🔐 演示 · 管理员登录与找回流程

本页面复刻主程序 index.html 的管理员账号逻辑（独立存储键 max_demo_admin，不影响正式数据）。
按步骤 1→5 依次操作即可完整走通：设置账号 → 登录 → 忘记密码 → 邮箱校验 → 重置密码。

1设置管理员账号（邮箱 + 密码）
相当于在主程序「爸妈后台 → 系统设置」里保存账号。密码只存 SHA-256 哈希，不存明文。
2登录验证（先试错误密码，再试正确密码）
对应主程序：点击顶栏「爸妈」按钮时弹出的登录框。邮箱或密码错误会被拦下。
3忘记密码 → 邮箱校验
登录框里点「忘记密码?」后要求输入注册邮箱。只有与注册邮箱完全一致才能进入重置。
本地版说明：现在是本地比对；云同步版本会升级为「邮箱验证码」，防他人在本机乱重置。
4设置新密码
邮箱校验通过后（本演示在步骤 3 通过后自动解锁此步），两次输入新密码完成重置。
5查看本地存储（可随时打开核对）
密码永远只以哈希形式存在。passHash 前 12 位相同 = 同一个密码。
